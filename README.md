# 🍋 Lemon Squeezy Homepage Clone

## ✨ Project Overview

This is a **faithful recreation of the Lemon Squeezy homepage**, built using **Next.js** and **Tailwind CSS**.

The project focuses on front-end accuracy, reproducing the original site's interface and layout.
*(Note: This is a static UI clone; no backend functionalities are implemented.)*

## 🚀 Technologies Used

* **Framework:** Next.js
* **Styling:** Tailwind CSS
* **Language:** TypeScript

## 🛠️ Getting Started

### Prerequisites

Ensure you have Node.js installed.

### Installation and Running

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/leopoldcanou/lemon-squeezy.git
    cd lemon-squeezy-clone
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    # or use yarn/pnpm/bun
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    # or yarn dev / pnpm dev / bun dev
    ```

Open [http://localhost:3000](http://localhost:3000) in your browser.
